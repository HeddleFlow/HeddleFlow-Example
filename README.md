# HeddleFlow Example

**An example project built with HeddleFlow, from an idea to running code.** Read it to see what a project looks like
with HeddleFlow at work, or fork it to try HeddleFlow on something real.

> **Status: not started.** The example is built once HeddleFlow can carry a product from an idea to its first running
> code. Until then this repository holds only this page.

## What you will find here

- **The product itself**, built by AI agents working through HeddleFlow, with a person deciding where it matters.
- **`.heddleflow/`**: HeddleFlow as this project installed it, including the Product Spine, every card from the
  first idea onward, with the specs and plans compiled from it.
- **`AGENTS.md`**, which every harness reads, and **`PROJECT.md`**, this project's own instructions for every agent.

## Kept current

Each time a HeddleFlow release is made public, this project moves to it with `uv run .heddleflow/hdf.py update`, the
same command every project uses, so the example always shows the latest release at work.

## Try it yourself

1. Fork this repository, then clone your fork.
2. Install Git, [uv](https://docs.astral.sh/uv/) and your harness.
3. Open the project in your harness and ask its agent what is next.

How to install HeddleFlow into a project of your own is in
[HeddleFlow/HeddleFlow](https://github.com/HeddleFlow/HeddleFlow).
